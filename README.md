# Tutorial Editor 

**Tutorial Editor** provides a seamless experience for knowledge experts to transform complex technical concepts into well-structured, interactive learning paths that can be monetized. 

Built with an enterprise-grade architecture, the platform bridges the gap between high-quality content creation and professional knowledge commerce.

## 🌟 Key Functionalities

- **Hierarchical Content Management:** Create and organize tutorials into chapters, steps, and sub-sections.
- **Rich Text & Code Integration:** Native support for markdown, syntax highlighting, and embedded media.
- **Role-Based Workspace:** Dedicated environments for Content Editors, Peer Reviewers, and Administrators.
- **Reactive User Interface:** Real-time feedback and state management during the content creation process.
- **Enterprise Security:** Fully integrated OpenID Connect (OIDC) authentication for secure multi-tenant access.

## 🛠️ Core Technology Stack

The project is built using a modern, scalable architecture:

- **Frontend:** Angular 19 (Standalone, Signals, Functional API).
- **Backend:** Spring Boot 3.x (Java 21).
- **Identity Management:** Keycloak (OIDC/OAuth2).
- **Database:** PostgreSQL.
- **DevOps:** Docker, Ansible, and Linux VPS hardening.
